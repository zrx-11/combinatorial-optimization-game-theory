# 《组合优化与博弈论》抽认卡

## 第 0 章

### 卡片：优化的三件套是什么？
- **背面**：决策变量、目标函数、约束条件
- **标签**：基础, 建模
- **章节**：ch00

### 卡片：可行解、可行域、最优解、最优值分别指什么？
- **背面**：满足约束的一组取值 / 所有可行解的集合 / 让目标最好的取值 / 最优解对应的目标数值
- **标签**：基础, 术语
- **章节**：ch00

### 卡片：为什么局部最优不一定是全局最优？
- **背面**：可行域可能有多个"山峰"，只看邻域会停在矮的那座
- **标签**：基础, 误解
- **章节**：ch00

### 卡片：连续优化与离散优化的分界在哪？
- **背面**：决策变量是否取离散值（整数、0-1、排列）；离散问题组合爆炸，通常更难
- **标签**：基础, 分类
- **章节**：ch00

## 第 1 章

### 卡片：线性规划标准形的四个条件？
- **背面**：最大化、约束全为等式、变量全非负、右端项非负
- **标签**：线性规划, 标准形
- **章节**：ch01

### 卡片：为什么最优解一定能在顶点找到？
- **背面**：目标函数是线性的，沿可行方向移动不会变差，直到撞到边界；顶点对应基本可行解
- **标签**：线性规划, 核心结论
- **章节**：ch01

### 卡片：检验数 σ_j 的含义？
- **背面**：非基变量 x_j 增加 1 单位时目标的增量；全 ≤ 0 即最优
- **标签**：单纯形, 判据
- **章节**：ch01

### 卡片：影子价格是什么？
- **背面**：某种资源增加 1 单位时最优目标的增量，等于对偶变量的值
- **标签**：对偶, 经济解释
- **章节**：ch01

## 第 2 章

### 卡片：产销平衡运输问题的约束矩阵秩是多少？
- **背面**：m + n − 1（总供给等于总需求带来一个线性相关）
- **标签**：运输, 结构
- **章节**：ch02

### 卡片：位势法里 σ_ij 怎么算？
- **背面**：σ_ij = c_ij − (u_i + v_j)；全 ≥ 0 时当前方案最优
- **标签**：运输, 检验
- **章节**：ch02

### 卡片：匈牙利算法的四步循环？
- **背面**：行减最小、列减最小、用最少直线覆盖零、未被覆盖处减最小并补回，直到能选 n 个独立零
- **标签**：指派, 算法
- **章节**：ch02

### 卡片：什么叫全么模，为什么重要？
- **背面**：所有方子阵行列式为 0 或 ±1；保证顶点为整数，LP 解可直接当整数解
- **标签**：全么模, 整数性
- **章节**：ch02

## 第 3 章

### 卡片：为什么不能把 LP 松弛解直接取整？
- **背面**：可能不可行（如 (2,4) 违反约束），也可能离最优很远（(2,3) 只有 −168，真最优 −198）
- **标签**：整数规划, 误解
- **章节**：ch03

### 卡片：Gomory 割从哪里来？
- **背面**：从最优表里右端项为分数的那一行，拆成整数部分与分数部分，得到只切分数顶点的新约束
- **标签**：割平面, 推导
- **章节**：ch03

### 卡片：分枝定界靠什么剪枝？
- **背面**：子问题的 LP 上界已不如手上最好的整数解（下界）时，整支剪掉
- **标签**：分枝定界, 剪枝
- **章节**：ch03

### 卡片：整数间隙是什么？
- **背面**：LP 松弛最优值与整数最优值之差，衡量"松弛有多松"
- **标签**：整数规划, 概念
- **章节**：ch03

## 第 4 章

### 卡片：Berge 定理说什么？
- **背面**：匹配最大当且仅当不存在增广路
- **标签**：匹配, 判据
- **章节**：ch04

### 卡片：Kruskal 与 Dijkstra 的区别？
- **背面**：Kruskal 求连通所有点的最小生成树（按边权从小到大挑不成圈的边）；Dijkstra 求单源最短路（按距离扩展）
- **标签**：图, 算法
- **章节**：ch04

### 卡片：最大流最小割定理？
- **背面**：maxflow = mincut，源到汇的最大流量等于分开源汇的最小割容量
- **标签**：网络流, 对偶
- **章节**：ch04

### 卡片：残余网络里为什么要有反向边？
- **背面**：允许撤销之前的流量分配，避免贪心卡在局部最优
- **标签**：网络流, 关键细节
- **章节**：ch04

## 第 5 章

### 卡片：P、NP、NP-完全、NP-难怎么区分？
- **背面**：P 多项式可解；NP 解可多项式验证；NP-完全 在 NP 内且所有 NP 可归约到它；NP-难 只需所有 NP 可归约到它
- **标签**：复杂度, 四盒
- **章节**：ch05

### 卡片：归约的方向怎么定？
- **背面**：把已知 NP-完全的问题 A 改写成待证问题 B，即 A ≤ₚ B
- **标签**：归约, 易错
- **章节**：ch05

### 卡片：强 NP-完全与一般 NP-完全的区别？
- **背面**：强 NP-完全的数值被规模多项式界住，故不存在伪多项式算法；背包是一般意义，TSP/装箱是强
- **标签**：复杂度, 强NPC
- **章节**：ch05

### 卡片：近似比 ρ 是什么？
- **背面**：算法解与最优解之比的最坏上界；ρ = 2 表示最坏差一倍
- **标签**：近似, 指标
- **章节**：ch05

## 第 6 章

### 卡片：α|β|γ 三段各写什么？

- **标签**：排序, 记法

### 卡片：1‖∑Cⱼ 和 1‖Lₘₐₓ 各用什么规则？

- **章节**：ch06

### 卡片：NF、FF、BF、FFD 的区别？
- **背面**：只看最后一只箱 / 从头找第一个装得下 / 找剩余最小的 / 先大后小再 FF
- **标签**：装箱, 算法
- **章节**：ch06

## 第 7 章

### 卡片：竞争比怎么定义？
- **背面**：所有输入序列上"在线花费 / 离线最优"的上确界
- **标签**：在线, 指标
- **章节**：ch07

### 卡片：滑雪租赁的最优竞争比？
- **背面**：2 − 1/N；随机化可到 e/(e−1) ≈ 1.58
- **标签**：在线, 经典
- **章节**：ch07

### 卡片：在线排序 LS 的界，以及何时最优？
- **背面**：2 − 1/m；m = 2、3 时最优；m = 4 下界变 √3
- **标签**：在线, 排序
- **章节**：ch07

### 卡片：Paging 与 k-server 什么关系？
- **背面**：Paging 是 k-server 的特例；LRU/FIFO 竞争比 k，WFA 竞争比 2k−1，下界 k
- **标签**：在线, 缓存
- **章节**：ch07

## 第 8 章

### 卡片：零和博弈什么时候有纯策略解？
- **背面**：max-min = min-max 时，公共值即博弈的值，对应鞍点
- **标签**：博弈, 零和
- **章节**：ch08

### 卡片：Nash 均衡的判据一句话？
- **背面**：没有任何参与者能单方面改变策略而提高收益
- **标签**：博弈, 核心
- **章节**：ch08

### 卡片：囚徒困境为什么是困境？
- **背面**：每个人理性选择"坦白"，集体结果却比都沉默更差——均衡不是最优
- **标签**：博弈, 反例
- **章节**：ch08

### 卡片：Cournot、Bertrand、Hotelling 各均衡在哪？
- **背面**：产量 (M−c)/3；价格压到成本 c；两家位置挤中点（三家无纯策略均衡）
- **标签**：博弈, 模型
- **章节**：ch08
