# 速查表

## 公式与结论

| 场景 | 内容 |
|---|---|
| 线性规划标准形 | max c x，s.t. Ax = b，x ≥ 0 |
| 基本解 | x_B = B⁻¹b，非基变量取 0 |
| 检验数 | σ_j = c_j − c_B^T B⁻¹ A_j，σ_j ≤ 0 全成立时最优 |
| 最小比值 | θ = min{b_i / a_ij : a_ij > 0} |
| 弱对偶 | 任意可行 x、y 有 c x ≤ b y |
| 影子价格 | y = (B⁻¹)^T c_B |
| 运输问题秩 | rank(A) = m + n − 1 |
| 位势检验 | σ_ij = c_ij − (u_i + v_j)，全 ≥ 0 时最优 |
| 整数规划三事实 | 松弛是下界；可行解变少但更难；无通用取整法 |
| MST 贪心 | Kruskal（按边权）/ Prim（按点扩） |
| Dijkstra | 非负权单源最短路，O(m log n) |
| 最大流最小割 | maxflow = mincut |
| 归约方向 | 已知 NPC 的 A ≤ₚ 待证 B |
| 强 NPC | B(I) ≤ p(x(I)) ⇒ 无伪多项式算法 |
| MST 双树法 | ρ = 2（需三角不等式） |
| FFD 装箱 | ≤ 11/9·OPT + 6/9 |
| SPT | 1‖∑Cⱼ 最优 |
| EDD | 1‖Lₘₐₓ 最优 |
| LPT | P‖Cₘₐₓ，ρ = 4/3 − 1/(3m) |
| LS | P‖Cₘₐₓ，ρ = 2 − 1/m |
| Johnson | F2‖Cₘₐₓ 最优规则 |
| 滑雪租赁 | 2 − 1/N；随机化 e/(e−1) |
| 找钥匙 | 最优竞争比 9 |
| Paging | LRU/FIFO 竞争比 k |
| k-server | WFA 竞争比 2k − 1，下界 k |
| 零和博弈 | max-min = min-max 时鞍点，值 v |
| 2×2 零和值 | v = (ad − bc)/(a + d − b − c) |
| Cournot | q = (M − c)/3，p = (M + 2c)/3 |
| Bertrand | p = c |
| 谈判解 | max (x − x₀)(y − y₀)，(x,y) ∈ S |

## 算法复杂度速记

| 问题 | 算法 | 复杂度 |

## 易错点清单

1. 单纯形最小比值只取正分母。
2. 影子价格不等于市价。
3. 取整 LP 解不保证可行。
4. 全么模看的是子阵行列式，不是元素大小。
5. 归约方向不能反。
6. 竞争比是上确界不是平均。
7. α|β|γ 中 β 为空要写空位，不能省。
8. Nash 均衡不等于社会最优。
