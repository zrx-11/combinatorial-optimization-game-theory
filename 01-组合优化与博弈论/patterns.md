# 模式与框架库

## 框架：优化的三件套

作者反复用同一个骨架描述一切优化问题：**决策变量 → 目标函数 → 约束条件**。拿到任何新场景，先把这三样写出来，问题就成型了。再补四个词（可行解、可行域、最优解、最优值），就能开始讨论解法。

**什么时候用**：任何"要怎么安排才最好"的问题，从排课到送货到投资组合。

**怎么用**：先问"我能决定什么"（变量），再问"好在哪"（目标），最后问"什么不能违反"（约束）。三者缺一，问题就是没定义清楚。

## 框架：难度分层

作者判断一个问题难不难，不看它长得复杂不复杂，而看它的**结构**：约束是等式还是不等式、变量是连续还是离散、矩阵是否全么模、有没有特殊结构（网络、超增、凸性）。

同一类问题里，结构的一个小改动会让难度跨数量级：最短路（多项式）vs 最长路（NP-难）、2-着色（多项式）vs 3-着色（NP-难）。**所以看到新问题，先找它离哪个已知问题最近。**

## 决策规则

```
要解一个优化问题
├─ 是连续的吗？
│   ├─ 是 → 线性？→ 单纯形法 / 内点法
│   └─ 否 → 约束矩阵全么模吗？
│        ├─ 是 → 直接解 LP，解自动整数
│        └─ 否 → 规模小？→ 割平面 / 分枝定界
│                规模大？→ 近似算法（先看有没有 PTAS/FPTAS）
└─ 信息不全吗？
    ├─ 完全不知未来 → 在线算法，用竞争比评价
    └─ 知道部分信息 → 半在线算法
```

## 决策规则：该用哪个"比"

| 场景 | 指标 | 含义 |
|---|---|---|
| 离线、有最优解可比 | 近似比 ρ | 最坏比最优差几倍 |
| 在线、未来未知 | 竞争比 ρ | 最坏比离线最优差几倍 |
| 多人博弈 | PoA | 最坏均衡比社会最优差几倍 |

三个指标的形式几乎一样（都是"最坏情况下的比值"），但比较对象不同。**记住这一点，就不会混用。**

## 反模式

**反模式 1：把 LP 松弛解直接取整。** 作者用第 3 章的三重失败证明它不可靠：取整可能不可行，也可能离最优很远。**替代方案**：割平面、分枝定界，或先证明全么模。

**反模式 2：用启发式的名字当保证。** "最近邻""模拟退火"听起来聪明，但没有理论界。**替代方案**：要么证明近似比，要么明确说"这是经验方法"。

**反模式 3：拿"平均表现"冒充"最坏保证"。** 竞争比、近似比都是上确界，平均数据好看不代表界好看。**替代方案**：分开报告"理论界"与"实测表现"。

**反模式 4：忽略前提条件。** 超增性、全么模、三角不等式、可行域有界——这些前提不成立时，结论就不成立。**替代方案**：用算法前先验前提。

**反模式 5：把"理性个体"当成"集体最优"。** 囚徒困境、Cournot 过度竞争、Bertrand 价格战，都是"每个人理性、集体受损"。**替代方案**：设计机制（合同、收费、规则）改变均衡。
